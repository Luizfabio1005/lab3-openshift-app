# lab3-openshift-app

Material de partida do **Laboratório Final 3 de Red Hat OpenShift** (curso 200DEV).

Conteúdo:

- `index.html`: página estática da aplicação "Agenda de Salas", com o texto `versão 1`.
- `Dockerfile`: imagem baseada em `registry.access.redhat.com/ubi9/nginx-126`. A aplicação escuta na porta **8080**.

Use este repositório pelo fork indicado no enunciado do laboratório. O enunciado indica quando alterar o conteúdo da aplicação.
